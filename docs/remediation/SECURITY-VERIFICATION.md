## Gate decision

- **G1 Authorization and scope: IMPLEMENTED; SQLite API VERIFIED.** The policy owner selected Option A (Union). PostgreSQL rerun of the new F-04 coverage remains **NOT VERIFIED**.
- **G2 Confidentiality: NOT VERIFIED.** Regression tests cover confidential balance, report, notification, Bradford and export paths, and manager-role direct-report rows are redacted; exhaustive evidence for every relevant API/export route has not been established.
- **G3 Employment lifecycle: PASS** for inclusive dates, expired manager service calls, and session rejection on next request. Proactive session revocation is absent.
- **G4 Account activation: PASS** for token security and single-use/rate limits.
- **G6 Audit integrity: NOT VERIFIED** because `TRUNCATE` was reproduced and role privileges are unknown. Raw INSERT is also not controlled by the triggers.
- **G9 Attachments: NOT VERIFIED** at infrastructure level; scan gating is tested, but production storage and real scanner are absent.
