## Independent Restore Drill Detail

The audit reran both repository scripts against separate PostgreSQL 17.11 source and restore containers, with an ephemeral age identity and a synthetic 35-byte attachment. The backup script produced encrypted database, attachment, and inventory artifacts. The restore script verified all three checksums, restored to an empty `zsh_restore_*` target, applied no missing migrations, passed `migrate --check`, `manage.py check`, foreign-key checks, and inventory comparison (`errors: []`, `database_vendor: postgresql`); restored attachment SHA-256 matched source. The source contained no production/business fixtures; entitlement reconciliation checked zero rows. This proves script behavior for a small synthetic dataset only, not production backup coverage or recovery objectives.
